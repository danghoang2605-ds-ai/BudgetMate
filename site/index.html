    The real app, tab by tab

    Five tabs: log, review, ask, analyse, follow the markets. These are unedited screenshots.

    Captured automatically by CI on an Android 14 emulator after every app change. The transactions are generated demo data; market figures are sample data shown when no API key is configured.

    Three ways to log, pick the fastest

    Keypad

    Amount, category, save. Whole dollars, a 00 key for round numbers, and a date picker for yesterday's lunch.

    Say it in a sentence

    Type what happened. The AI reads the amount, picks the category and saves it, or answers if you asked a question instead.

    This page parses with a simple pattern in your browser. The app sends the sentence to an AI model and validates the reply before saving.

    Snap the receipt

    Point the camera at a bill. ML Kit reads the text on the phone, the AI finds the total, and you confirm before it is saved.

    See the whole month at a glance

    Week, month, year
    Grouped bars for income against expenses, a cash-flow line, and pie and radar charts by category.
    All-time totals
    Lifetime income, expenses and net next to the month you are looking at, plus the change from last month.
    Export
    One tap writes a CSV for spreadsheets and a PDF summary to the phone.

    Your money data stays on your phone

    No sign-up and no cloud database. The only network calls are the ones you turn on.

    Storage
    Transactions live in an on-device SQLite database (Room). Uninstalling the app removes them.
    AI
    Optional. Requests go through a small proxy you deploy, so no AI key ships inside the app. Only the sentence or receipt text is sent.
    Network
    HTTPS only. News and stock data load only when you add your own API keys; otherwise the app shows sample data.

    How it's built

    A native Java app by Dang Hoang. The code, tests and CI are open on GitHub.

    Java + MVVMFragments, ViewModel and LiveData over a repository layer.
    Room databaseVersioned schema with explicit migrations, tested on SQLite with Robolectric.
    Retrofit + OkHttpNews, stocks and the AI chat, with errors shown instead of swallowed.
    ML Kit + CameraXOn-device text recognition for receipts.
    MPAndroidChartBar, line, pie and radar charts tuned for a dark theme.
    GitHub ActionsUnit tests, an APK on every push, and these screenshots from an emulator.
